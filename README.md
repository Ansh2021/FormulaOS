# Formula OS
## A lightweight web-based operating system for Formula One

Made for Hack Club's Stardance

## Apps
Currently features three different apps:
- Notes
  - Based off the iOS Notes App
  - Take as many notes as your heart desires
- Calculator
  - Simple four function calculator
- Terminal
  - Terminal with working commands
  - Examples include:
    - Fun fact
    - Random circuit
    - Random driver
